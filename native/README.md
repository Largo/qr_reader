# qr_reader-native

Optional native speed-up for [qr_reader](https://github.com/largo/qr_reader).

qr_reader is pure Ruby. Its hot loops (image decoding, binarization, pattern
scanning) are written as plain-Ruby "kernels" in a subset of Ruby that the
[Spinel](https://github.com/matz/spinel) AOT compiler understands. This gem is
those very kernels compiled to C by Spinel: install it next to qr_reader and
qr_reader uses them automatically.

```ruby
# Gemfile
gem "qr_reader"
gem "qr_reader-native"   # optional; needs a C compiler at install time
```

```ruby
require "qr_reader"
QrReader.native?          # => true when the native kernels are in use
```

- Same results: the native kernels are compiled from the same source as the
  Ruby ones and are tested against them.
- Safe to omit: without this gem, or on Rubies without C extensions (JRuby,
  ruby.wasm, ...), qr_reader runs the same code as Ruby.
- Version-locked: it depends on the identical qr_reader version and is only
  used when its kernel digest matches the installed qr_reader.
- `QR_READER_NATIVE=0` disables it at runtime.

Installing compiles about 4 MB of generated C (Spinel's runtime included);
Spinel itself is not needed.
